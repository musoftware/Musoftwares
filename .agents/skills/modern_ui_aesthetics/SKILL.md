# Modern UI Aesthetics

When generating user interfaces, your design must look premium, modern, and engaging. A basic, unstyled layout is unacceptable.

## Core Rules

1. **Typography**: Use modern, readable fonts (e.g., Inter, Roboto, Outfit). Establish a clear typographic hierarchy with distinct sizes and weights.
2. **Color Palettes**: Avoid generic colors (pure red, blue, green). Use curated, harmonious color palettes (e.g., HSL tailored colors) and provide sleek dark modes if applicable.
3. **Dynamic Interaction**: An interface should feel alive. Add hover effects, focus states, and subtle micro-animations (e.g., slight scaling on button hover, smooth transitions) for an enhanced user experience.
4. **Consistent Spacing**: Use a consistent spacing scale (like Tailwind's default spacing) to ensure padding and margins are uniform throughout the application.
