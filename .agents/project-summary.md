# Project Summary

## Overview
Musoftware is a multi-tenant enterprise system built with Laravel (Backend) and React/Inertia.js (Frontend). It features a highly modular architecture using `nwidart/laravel-modules` to separate business domains (ERP, CRM, GoldSavers, Marketplace, etc.).

## Tech Stack
- **Backend**: Laravel 12.x, PHP 8.2+
- **Frontend**: React 18, Inertia.js 2.0, TailwindCSS 4.x
- **UI Components**: Shadcn UI (Radix UI primitives)
- **Database**: MySQL/MariaDB
- **State Management**: Spatie Model States (Backend), React Context/Hooks (Frontend)
- **Auth/Permissions**: Laravel Sanctum, Spatie Permission
- **Testing**: PHPUnit / Pest
